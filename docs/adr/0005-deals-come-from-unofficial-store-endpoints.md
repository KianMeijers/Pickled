# Deals come from unofficial store endpoints, within a private-use budget

Neither Albert Heijn nor Jumbo has a public API, so Deals are read from endpoints the stores never offered for this. AH comes from the Appie mobile API (`api.ah.nl`, anonymous token). AH's terms allow personal use, but its app terms forbid reverse engineering; we only call endpoints already documented by open-source clients. Jumbo comes from the `__NUXT_DATA__` payload on `jumbo.com/aanbiedingen/nu`. Jumbo's terms forbid scraping and have no personal-use exception. We accept both risks because Pickled is a private tool for one Household. Hard rules follow from that: a realistic browser or app User-Agent, about 30 requests per store per week at most (so we read listing pages and don't expand every promotion into its products), the data is never redistributed, and Pickled is never hosted for anyone outside the Household. The alternatives were AH only, which loses half the Deals, and paid aggregators, which are scrapers of the same pages with an extra middleman. **If Pickled ever serves other households, this decision has to be made again before launch.**
