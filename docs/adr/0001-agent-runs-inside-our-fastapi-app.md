# The agent runs inside our own FastAPI app, not LangGraph's Agent Server

The agent is built with LangChain's `create_agent` (which runs on LangGraph) and is hosted inside Pickled's own FastAPI app. Conversation state is persisted with LangGraph's Postgres checkpointer in the same Postgres database as the rest of the app. We stream to the browser through our own SSE endpoint, which HTMX consumes. We considered LangGraph's Agent Server (formerly LangGraph Platform), which provides threads, background runs, cron and streaming out of the box. We rejected it because production self-hosting needs an Enterprise licence, Redis and an outbound licence check, and its package is Elastic License 2.0. The cheapest hosted option is $39/seat/month. That breaks the budget and the "nothing paid except the LLM" rule. As a result, scheduling and background runs are ours to build (see "How does background work get scheduled and run?").
